Фитнес-приложение
Веб-приложение, в котором пользователь ведёт тренировки, питание и прогресс в одном интерфейсе. Дипломный проект, ЮЗГУ, программная инженерия, 2026.
Что внутри
- Интерфейс на HTML, CSS и JavaScript: план тренировок, каталог упражнений, питание, профиль, социальная лента, графики прогресса.
- Сервер на Node.js и Express, данные в PostgreSQL.
- Регистрация и вход по JWT, профиль, тренировки, хранилище данных, социальная лента.
- Тесты маршрутов: `npm test` в папке `backend`.
